# Milestone 0: Sprite Path

Purpose:

```text
Prove one wall-card-like sprite strip can be displayed, shrunk, palette-swapped, and moved.
```

Initial checklist:

```text
choose SDK/toolchain path
build a minimal ROM
define one 16x512 card or smaller test strip
write SCB tile/position/shrink/palette data
show frame counter on fix layer
toggle shrink and palette with controls
record sprite count and update cost
```

No Doom renderer belongs here.
